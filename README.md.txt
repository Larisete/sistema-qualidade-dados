Projeto Integrador – Fase 1 

Levantamento de Requisitos 

Nome da Squad: DataTech 

1. Escopo do Sistema 

O sistema terá como objetivo consumir dados brutos de vendas, verificar se os dados estão corretos e mostrar os resultados de forma simples para o usuário. O sistema deverá ajudar na identificação de possíveis erros ou problemas nos dados. 

2. Requisitos Funcionais (RF) 

RF01: O sistema deve permitir que o usuário faça upload de um arquivo CSV de vendas. 

RF02: O sistema deve verificar se os dados do arquivo estão completos e corretos. 

RF03: O sistema deve mostrar os resultados da validação dos dados para o usuário. 

RF04: O sistema deve informar quando forem encontrados erros ou dados faltando no arquivo. 

3. Requisitos Não-Funcionais (RNF) 

RNF01: O sistema deve ser fácil de usar e ter uma interface simples. 

RNF02: O sistema deve realizar a validação dos dados em poucos segundos. 

RNF03: O sistema deve manter os dados enviados pelo usuário protegidos.
